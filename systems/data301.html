Proposition

Twelve interactive ML laboratories whose core numerical functions remain framework-independent and directly testable outside the interface.

What is technically difficult

Educational software can become decorative. DATA301 connects visual interaction to inspectable TypeScript algorithms and uses exact examples plus metamorphic properties to protect the underlying mathematics.

Evidence

Interactive surface12 implemented laboratories across regression, classification, clustering, PCA, optimization, trees, SVM, curves, and ensembles.
Source protection36 source tests including 7 metamorphic properties.
Release gateFail-closed lockfile finalization, 36 tests, typecheck, production build, public/private scan, and dependency audit.
Boundary designSanitized public edition with explicit authorization and private-storage architecture.

Where the claim stops

Educational two-dimensional algorithms and synthetic examples; no production cohort, concurrency, or model-serving claim.
