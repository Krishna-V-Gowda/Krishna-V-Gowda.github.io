Proposition

A C++20 event-replay engine for a bounded TotalView-ITCH subset, with explicit state transitions and an independently implemented Python oracle.

What is technically difficult

One incorrect byte offset, partial fill, cancellation, replacement, or level update can silently corrupt every downstream state. The repository makes those errors observable through typed decoding, reconstructed invariants, canonical output, malformed-input tests, and cross-language differential evidence.

Evidence

Native core17 C++ tests for decoder and state transitions.
Independent reference5 Python oracle tests and exact canonical-state identity.
Adversarial matrix18 differential scenarios and 128 deterministic corruptions.
Retained workload500,000 synthetic messages with environment and raw timings preserved.

Where the claim stops

Documented subset only. No live transport, sequence-gap recovery, captured proprietary feed, exchange certification, or universal performance claim.

Deep inspection

The repository is the authoritative technical artifact. Start with its README, then architecture, tests, retained evidence, and limitations.
