Proposition

TrustBench executes the exact shipped browser-side Apex source against independent numerical references and metamorphic properties; Apex is the real product subject and remediation target.

What is technically difficult

A rewritten formula can make a test pass while the shipped product remains wrong. TrustBench extracts named functions from the actual JavaScript bundle, fingerprints the source, runs it in an isolated Node boundary, and compares it with independent Python calculations.

Evidence

Controlled baseline7 passes, 2 definition divergences, 4 limitations, and 3 failed invariants.
Post-repair15 passes, one documented low-severity limitation, and zero failures.
ReproductionExact source hashes, patch, counterexamples, transition manifest, and generated reports.
Regression layer7 dependency-free Apex exact-source regressions plus 13 TrustBench delivery tests.

Where the claim stops

The current adapter verifies selected behavior in a documented Apex release; it is not a universal certifier for all analytical software.

Deep inspection

The repository is the authoritative technical artifact. Start with its README, then architecture, tests, retained evidence, and limitations.
