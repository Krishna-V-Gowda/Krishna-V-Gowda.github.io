    MarketReplay

    A C++20 engine that rebuilds a stock exchange’s order book from its binary message feed (Nasdaq TotalView-ITCH), one message at a time.

    A separate Python implementation replays the same feed. Both must end in exactly the same state, byte for byte, across 500,000 messages.

    A bounded subset of ITCH. Not a live trading system.

    TrustBench

    TrustBench takes the exact code an analytics app ships and checks its statistics against independent reference libraries.

    Its first subject, Apex, passed 7 of 16 checks. After the fixes, 15 of 16. TrustBench recorded the fixed code’s fingerprint, and this panel checks that the live app still matches it.

    Checks one documented Apex release, not any analytics tool.

    Change one letter and about half the fingerprint changes. So when the live app’s fingerprint matches, the code is identical, byte for byte.

    RiskLab

    A research lab for one question: which ways of splitting money across assets still hold up when estimates are noisy, markets change mood and trading costs money?

    Six methods run through a simulated market with a calm spell, a crash, a recovery and an inflation scare. The crash is brutal on purpose, so every method loses. What matters is which loses least, and whether that difference is real.

    Simulated markets, not historical returns or advice.
